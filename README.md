# Grand Duchy Media

A modern and responsive digital agency website built with React, Vite, Tailwind CSS, and Framer Motion.

## ✨ Features

- Modern responsive UI
- Website Development portfolio
- Graphics Design showcase
- Social Media Marketing section
- Long-Form Video Production
- Short-Form Content (TikTok, Reels & Shorts)
- Auto-playing videos with play/pause controls
- Mute/Unmute functionality
- Infinite marquee animations
- Smooth Framer Motion animations
- Mobile-friendly design

## 🛠 Tech Stack

- React.js
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## 📁 Project Structure

## 🚀 Installation

```bash
git clone https://github.com/Mustee-coder/grand-duchy-media.git

cd grand-duchy-media

npm install

npm run dev
```
